# Industrial Plant Design — Course Learning Hub (17 Weeks)

หน้าเว็บไซต์หลักสำหรับลิงก์ไปยังสื่อการสอน Interactive HTML รายวิชา **การออกแบบโรงงานอุตสาหกรรม** (รหัส 03-407-051-307) มหาวิทยาลัยเทคโนโลยีราชมงคลอีสาน นครราชสีมา

หน้าแรกมี **ไอคอน SVG 17 ภาพ** ซึ่งออกแบบให้ตรงกับหัวข้อการเรียนในแต่ละสัปดาห์, ช่องค้นหาบทเรียน, ตัวกรองตามขั้นการเรียนรู้, ส่วนแสดงเส้นทางการเรียนรู้ 4 ระยะ, และการตรวจสอบสถานะไฟล์ HTML อัตโนมัติ

## 1. โครงสร้างไฟล์

```text
Industrial_Plant_Design_Course_Hub/
├── index.html                      ← หน้าแรกของเว็บไซต์
├── .nojekyll                       ← สำหรับ GitHub Pages
├── README.md
├── assets/
│   ├── site.css                    ← รูปแบบเว็บไซต์
│   └── icons/
│       ├── week-01.svg             ← รูปไอคอนสัปดาห์ 1
│       ├── ...
│       └── week-17.svg             ← รูปไอคอนสัปดาห์ 17
├── js/
│   ├── config.js                   ← ตั้งชื่อบทเรียนและลิงก์ (แก้ไขไฟล์นี้)
│   └── app.js                      ← ระบบค้นหา/กรอง/ตรวจสอบลิงก์
└── lessons/                         ← วาง HTML ของบทเรียนรายสัปดาห์ที่นี่
    ├── Industrial_Plant_Design_Week_01_Interactive.html
    ├── Industrial_Plant_Design_Week_02_Interactive.html
    ├── ...
    └── Industrial_Plant_Design_Week_17_Interactive.html
```

**สำคัญ:** ZIP นี้สร้างเฉพาะหน้าแรกพร้อมไอคอน ไม่ได้มีบทเรียน HTML ครบ 17 สัปดาห์ เนื่องจากไฟล์ที่ได้รับเป็น PDF แผนการสอนและ TXT บันทึกอ้างอิงเท่านั้น หากไม่มีไฟล์ HTML ของสัปดาห์ใด ระบบจะแสดง `รออัปโหลดไฟล์` แทนการเปิดหน้าเสีย

## 2. นำขึ้น GitHub Pages

1. สร้าง Repository บน GitHub เช่น `industrial-plant-design` (เลือก **Public** หากต้องการให้ทุกคนเข้าถึง)
2. แตก ZIP แล้วอัปโหลด **ไฟล์และโฟลเดอร์ภายใน** `Industrial_Plant_Design_Course_Hub` ขึ้นที่ระดับบนสุด (root) ของ Repository — ให้ `index.html` อยู่ที่ root
3. เปิดแท็บ **Settings → Pages** แล้วเลือก **Build and deployment: Deploy from a branch**, **main** และ **/(root)** จากนั้น Save
4. หลัง GitHub Pages เผยแพร่ เว็บจะมีรูปแบบประมาณ `https://YOUR-USERNAME.github.io/industrial-plant-design/`
5. เมื่อมีไฟล์สื่อแต่ละสัปดาห์ ให้นำ HTML ใส่ในโฟลเดอร์ `lessons/` ตามชื่อที่ตั้งใน `js/config.js` จากนั้นอัปโหลด/commit เว็บไซต์จะแสดงสถานะ `พร้อมเรียน` อัตโนมัติหลังเผยแพร่ไฟล์

> **อย่าลืม** หากบทเรียน HTML มีรูปภาพ/CSS/JS เป็นไฟล์แยก ให้คัดลอกไฟล์เหล่านั้นไปพร้อมกันและรักษา path เดิมภายในบทเรียน เพื่อไม่ให้รูปและกิจกรรมเสีย

## 3. เปลี่ยนชื่อไฟล์/ลิงก์รายสัปดาห์

แก้ไข `js/config.js` โดยเพิ่ม `file` ที่รายการสัปดาห์ที่ต้องการ:

```js
{ week: 1, phase:'foundation', title:'รู้จักโรงงานและการออกแบบผัง',
  en:'Introduction to Industrial Plant Design',
  topics:['องค์ประกอบโรงงาน','เป้าหมายของผังที่ดี'],
  summary:'ทำความรู้จัก...',
  file:'lessons/week1/my-first-lesson.html' },
```

- ถ้าตั้งชื่อไฟล์ตามมาตรฐาน `lessons/Industrial_Plant_Design_Week_01_Interactive.html` อยู่แล้ว **ไม่ต้องแก้ค่า `file`**
- สามารถใช้ลิงก์เว็บไซต์เต็ม เช่น `file:'https://example.com/lesson1.html'` ระบบจะเปิดลิงก์นั้นในหน้าเดิม
- ค่าปริยาย `published: 'auto'` จะตรวจสถานะไฟล์จริงโดยอัตโนมัติสำหรับไฟล์ที่อยู่ใน GitHub Pages เดียวกัน
- กำหนด `published: true` เพื่อเปิดลิงก์ทันที (เหมาะกับสื่อบนเว็บอื่นที่ตรวจผ่านเบราว์เซอร์ไม่ได้)
- กำหนด `published: false` เพื่อแสดงเป็นรออัปโหลดเสมอ

## 4. เปิดทดสอบในเครื่องก่อนอัปโหลด

ใช้ **Live Server** ใน VS Code หรือคำสั่ง Python โดยเปิด Terminal ในโฟลเดอร์เว็บไซต์:

```bash
python -m http.server 8000
```

แล้วเปิด `http://localhost:8000/` เพื่อให้ระบบตรวจสอบไฟล์ใน `lessons/` ได้

> การดับเบิลคลิก `index.html` เพื่อเปิดด้วย `file://` ยังคงดูหน้าเว็บไซต์ได้ แต่ระบบตรวจสอบไฟล์อัตโนมัติจะไม่ทำงานเนื่องจากข้อจำกัดความปลอดภัยของเบราว์เซอร์

## 5. ปรับแต่งสี/รูปภาพ

- CSS อยู่ที่ `assets/site.css`
- ภาพไอคอนแต่ละสัปดาห์อยู่ที่ `assets/icons/week-XX.svg` (ไฟล์ SVG คมชัดทุกหน้าจอ)
- เปลี่ยนข้อความ/หัวข้อ/กิจกรรมประจำสัปดาห์ได้ใน `js/config.js`
- หน้าเว็บนี้เป็นเว็บไซต์แบบ **Static HTML + CSS + JavaScript** ไม่ต้องใช้ฐานข้อมูลหรือเซิร์ฟเวอร์แอปพลิเคชัน
