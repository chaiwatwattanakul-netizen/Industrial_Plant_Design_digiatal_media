03 / THEORY & EQUATIONS

ทฤษฎี สมการ และสัญลักษณ์มาตรฐาน

ประเมินทั้ง ระยะทางขนย้ายถ่วงน้ำหนัก (Load-Distance) และ คะแนนรวมถ่วงน้ำหนัก (Weighted Scoring) จึงต้องแยกข้อสรุป “ต้นทุนต่ำที่สุด” ออกจาก “คะแนนรวมสูงที่สุด”

dᵢⱼ = |xᵢ−xⱼ| + |yᵢ−yⱼ|
LD = Σ Fᵢⱼ dᵢⱼ  ;  TCⱼ = LDⱼ × c
S_cost,j = 5 × (TC_min / TCⱼ)   เมื่อ TCⱼ > 0
Sⱼ = [w₁r₁ⱼ + w₂r₂ⱼ + w₃r₃ⱼ] / 100
ΔS = S_B − S_A
สัญลักษณ์ความหมายภาษาไทย (English Name)หน่วย
R / C / D / Pวัตถุดิบ / ตัด / เจาะ / บรรจุ (Raw Material / Cutting / Drilling / Packing)–
Fᵢⱼจำนวนเที่ยวขนย้าย (Material Handling Trips)เที่ยว/วัน
dᵢⱼระยะทางแนวฉาก (Rectilinear Distance)เมตร
LDระยะทางขนย้ายถ่วงน้ำหนัก (Load-Distance)เที่ยว·เมตร/วัน
cอัตราต้นทุนขนย้าย (Handling Cost Rate)บาท/เที่ยว·เมตร
TCⱼ / TC_minต้นทุนผัง j / ต้นทุนต่ำสุด (Handling Cost / Minimum Cost)บาท/วัน
S_cost,jคะแนนต้นทุนที่ปรับมาตรฐาน (Normalized Cost Score)คะแนน
wᵢน้ำหนักเกณฑ์ (Criterion Weight)%
rᵢⱼคะแนนเกณฑ์ i ของผัง j (Criterion Rating)คะแนน
Sⱼ / ΔSคะแนนรวม / ผลต่าง B−A (Weighted Score / Score Difference)คะแนน
เงื่อนไขทางคณิตศาสตร์: สูตรคะแนนต้นทุนแบบอัตราส่วนอาจให้คะแนนต่ำกว่า 1 เมื่อมีต้นทุนสูงกว่าต้นทุนต่ำสุดมาก จึงไม่รับประกันว่าทุกค่าจะอยู่ในช่วง 1–5 แต่ข้อมูลตั้งต้นอยู่ในช่วงนี้ กรณีต้นทุนสองผังเป็นศูนย์กำหนดให้ทั้งคู่ 5 คะแนน; ถ้ามีต้นทุนศูนย์เพียงผังเดียว กำหนด 5 คะแนนให้ผังนั้นและ 0 ให้อีกผัง เพื่อหลีกเลี่ยงการหารด้วยศูนย์

07 / SHORTCUT & SENSITIVITY

วิธีลัดและการทดลองเปลี่ยนน้ำหนัก

แทนการรวมคะแนนสองครั้ง ใช้ผลต่างคะแนนของแต่ละเกณฑ์แล้วคูณน้ำหนักโดยตรง

ΔS = (w_cost × Δr_cost + w_safety × Δr_safety + w_flex × Δr_flex) / 100
หาก ΔS > 0 เลือกผัง B; ΔS < 0 เลือกผัง A; ΔS = 0 ทั้งสองผังมีคะแนนเสมอกัน ต้องพิจารณาเกณฑ์อื่นเพิ่มเติม ตรวจเงื่อนไขข้อห้ามจริงก่อนใช้ในโรงงาน
