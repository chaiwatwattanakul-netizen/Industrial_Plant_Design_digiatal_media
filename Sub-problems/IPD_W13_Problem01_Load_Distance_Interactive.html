ทฤษฎีและสมการ

1. Rectilinear Distance
Dij = |xi − xj| + |yi − yj|
หน่วย: เมตร
2. Load-Distance
LD = Σ(Fij × Dij)
หน่วย: เที่ยว·เมตร/วัน
3. ต้นทุนการขนย้าย
TC = LD × c (บาท/วัน)
Fij = เที่ยวขนย้ายต่อวัน, Dij = ระยะทางระหว่างแผนก (ม.), c = บาท/(เที่ยว·เมตร)
หลักคิด: แผนกที่ขนย้ายหากันบ่อยควรอยู่ใกล้กัน โดยพิจารณาความถี่และระยะทางร่วมกัน โจทย์นี้มุ่งหาต้นทุนต่ำที่สุด จาก 3 ผังที่กำหนด ไม่ใช่การพิสูจน์ว่าผังดีที่สุดในทุกเงื่อนไขของโรงงานจริง
02

โจทย์ปัญหาและข้อมูล

โรงงานผลิตชิ้นส่วนโลหะมีพื้นที่ 4 แผนก ได้แก่ R = คลังวัตถุดิบ, C = ตัด, D = เจาะ และ P = บรรจุ ฝ่ายวิศวกรรมเสนอผัง A, B, C โดยมีตำแหน่งแผนกต่างกัน ต้องการเลือกผังที่มี ต้นทุนการขนย้ายวัสดุต่อวันต่ำที่สุด

สมมติฐานสำคัญ: ช่องอยู่ติดกันห่าง 10 ม. ระหว่างจุดศูนย์กลาง ขนย้ายตามแนวนอน–แนวตั้งเท่านั้น ค่าใช้จ่าย 2 บาท/(เที่ยว·เมตร) ไม่รวมเที่ยวกลับ ไม่มีสิ่งกีดขวาง และทุกผังผ่านเงื่อนไขพื้นที่และความปลอดภัยแล้ว

ตาราง From-To (ข้อมูลเริ่มต้น)

เส้นทางจำนวนเที่ยว / วัน
R → C
C → D
D → P
C → P

③ ต้นทุนขนย้ายต่อวันของทุกผัง
④ ผังที่มีต้นทุนต่ำที่สุด พร้อมผลประหยัด

แผนผัง Grid 2×2 พร้อมลูกศรและจำนวนเที่ยว (แก้ไขตำแหน่งได้)

03

วิธีคำนวณด้วยมือ ทีละขั้นตอน

  1. เขียนข้อมูลจำนวนเที่ยว จากตาราง From-To: R→C, C→D, D→P และ C→P แล้วรวมจำนวนเที่ยวทั้งหมด (ข้อมูลเริ่มต้นรวม 84 เที่ยว/วัน)
  2. หาระยะทาง Dij จากแต่ละผัง เช่น ผัง A เส้น R→C ติดกันในแนวตั้ง จึงได้ 10 ม.; ส่วน C→P อยู่ทแยงกัน ต้องเดิน 10+10 = 20 ม.
  3. คูณจำนวนเที่ยวกับระยะทาง ของทุกเส้นทาง: คำนวณ F×D ทีละแถวและนำมาบวกเป็น LD ของแต่ละผัง
  4. แปลงเป็นต้นทุน โดยนำ LD คูณค่าขนย้ายต่อเที่ยว·เมตร และเปรียบเทียบต้นทุนของผัง A/B/C เพื่อเลือกค่าต่ำสุด
ตัวอย่างผัง A จากโจทย์เริ่มต้น
ระยะทาง R→C = 10, C→D = 10, D→P = 10 และ C→P = 20 เมตร
LDA = (30×10) + (24×10) + (24×10) + (6×20) = 900 เที่ยว·เมตร/วัน
TCA = 900×2 = 1,800 บาท/วัน

หากเปลี่ยนข้อมูลหรือตำแหน่งผัง ให้ใช้ขั้นตอนข้างต้นคำนวณใหม่ แล้วเปิดแนวเฉลยอัปเดตด้านล่าง

เปิดแนวเฉลยคำนวณด้วยมือครบทั้ง 3 ผัง (แสดงที่มาและผลทีละแถว)

06

วิธีลัดและการพิสูจน์คำตอบ

โจทย์นี้ทุกผังเป็นตาราง 2×2 ช่อง ความยาวระหว่างช่องเท่ากัน จึงมีระยะทางเพียงสองแบบ คือ ติดกัน = s และ ทแยง = 2s ทำให้คำนวณ LD ได้เร็วโดยไม่ต้องคูณทุกเส้นทางใหม่

LD = s × (ผลรวมเที่ยวทุกเส้นทาง) + s × (ผลรวมเที่ยวของเส้นทางที่อยู่ ทแยง)
เปิดการคำนวณวิธีลัดสำหรับผัง A / B / C (อัปเดตตามค่าที่แก้)
กำลังเตรียมการคำนวณ...

วิธีลัดด้วย Excel

ในไฟล์ Excel ที่ให้ดาวน์โหลด จำนวนเที่ยวอยู่ในแผ่น “ข้อมูลและผัง” เซลล์ C12:C15 และระยะทางผัง A อยู่ในแผ่น “คำนวณละเอียด” เซลล์ D10:D13 จึงใช้สูตร SUMPRODUCT คำนวณ LD ได้ในบรรทัดเดียว

=SUMPRODUCT('ข้อมูลและผัง'!C12:C15,'คำนวณละเอียด'!D10:D13)

สูตรข้างบนเป็นตัวอย่างช่วงเซลล์แบบย่อ ส่วนไฟล์ Excel ฉบับสมบูรณ์ใช้ข้อมูลจริงในแผ่น “ข้อมูลและผัง” และสูตรในแผ่น “คำนวณละเอียด” โดยคำนวณให้ครบ 3 ผังอัตโนมัติ

ไฟล์ Excel มี 4 แผ่นงาน: คู่มือและสรุป • ข้อมูลและผัง • คำนวณละเอียด • วิธีลัด เปิดได้โดยไม่ต้องใช้บริการออนไลน์ ข้อมูลในไฟล์เริ่มต้นเป็นโจทย์ตั้งต้น; หากเปลี่ยนข้อมูลใน HTML ให้แก้ช่องสีเหลืองใน Excel ตามเพื่อเปรียบเทียบกรณีเดียวกัน

สำหรับผัง B หรือ C เปลี่ยนคอลัมน์ระยะทางจาก D เป็น F หรือ H ตามลำดับ; อัตราค่าขนย้ายเท่ากันทุกผังจึงเรียงลำดับด้วยค่า LD ได้เลย แต่ต้องคูณต้นทุนอีกครั้งเพื่อรายงานค่าเป็นบาท/วัน

สูตรลัดข้างต้นใช้ได้เพราะระยะห่างเป็นช่องสม่ำเสมอ และแต่ละคู่แผนกในผัง 2×2 มีระยะทาง s หรือ 2s เท่านั้น สำหรับผังจริงที่ซับซ้อนต้องกลับไปใช้สูตรระยะทางและ LD ทั่วไป
