03 / THEORY & EQUATIONS

ทฤษฎี สมการ และตารางสัญลักษณ์

ระยะทางแนวฉาก (Rectilinear / Manhattan Distance)

dᵢⱼ = g ( |xᵢ − xⱼ| + |yᵢ − yⱼ| )

ระยะทางขนย้ายถ่วงน้ำหนัก (Load-Distance)

LDₖ = Σ ( Fᵢⱼ × dᵢⱼ,ₖ )

ต้นทุนขนย้าย (Material Handling Cost)

TCₖ = LDₖ × c ; เลือกผังที่ min(TCₖ)
สัญลักษณ์ความหมายภาษาไทย (English Name)หน่วย
R, C, D, Pคลังวัตถุดิบ / ตัด / เจาะ / บรรจุ (Raw Material / Cutting / Drilling / Packing)–
Fᵢⱼจำนวนเที่ยวจาก i ไป j (Directed Material Flow)เที่ยว/วัน
xᵢ, yᵢพิกัดของแผนก (Department Grid Coordinates)ช่อง
gระยะห่างศูนย์กลางช่อง (Grid Spacing)เมตร/ช่อง
dᵢⱼระยะทางระหว่างแผนก (Rectilinear Distance)เมตร
LDₖระยะทางถ่วงน้ำหนักของผัง k (Layout Load-Distance)เที่ยว·เมตร/วัน
cอัตราต้นทุนขนย้าย (Handling Cost Rate)บาท/(เที่ยว·เมตร)
TCₖต้นทุนขนย้ายของผัง k (Total Handling Cost)บาท/วัน
Fₜ, Fᵈเที่ยวรวม (Total Trips), เที่ยวคู่ทแยง (Diagonal Trips)เที่ยว/วัน
i, j, kดัชนีแผนกและผัง (Department / Layout Indices)–
ข้อจำกัด: ค่า TC ต่ำที่สุดหมายถึงต่ำสุดเฉพาะ 3 ผังที่นำมาเปรียบเทียบ และภายใต้สมมติฐานขนส่งเหมือนกันทุกเส้นทาง ไม่ได้ยืนยันต้นทุนรวมโรงงานต่ำสุดเมื่อรวมการย้ายเครื่องจักร ความปลอดภัย และพื้นที่เดินรถจริง

05 / INTERACTIVE LAYOUT EXPLORER

ผัง Grid 3 แบบ พร้อมลูกศร ปริมาณเที่ยว และระยะทาง

แต่ละช่องอยู่ห่างกันตาม g เมตร เลือกดูทีละเส้นทางเพื่อให้อ่านลูกศรชัดเจน หรือเลือก “ทุกเส้นทาง” เพื่อดูภาพรวม สามารถเปลี่ยนตำแหน่งแผนกในแต่ละช่องด้านล่างภาพได้ โดยระบบสลับแผนกเพื่อรักษารหัสไม่ให้ซ้ำ

เส้นลูกศรแสดงทิศทางการขนย้าย (Directed Flow) และระยะทางแนวฉากที่คำนวณจากพิกัดศูนย์กลางแผนก เส้นที่อยู่ใต้บล็อกถูกบังโดยสัญลักษณ์แผนกเพื่อรักษาความอ่านง่าย (ไม่ใช่ผังทางเดินจริง)
