01 / LEARNING OBJECTIVES

ความเชื่อมโยงกับแผนการสอน

สัปดาห์หลักที่ 12 — ระบบขนถ่ายวัสดุและความปลอดภัย (Material Handling Systems)

ตามแผนการสอน 17 สัปดาห์ ครอบคลุมการเลือกอุปกรณ์ Forklift / Conveyor / AGV–AMR การเปรียบเทียบความสามารถ และการคำนวณจำนวนเที่ยวหรือจำนวนรถอย่างง่าย

เชื่อมโยง: สัปดาห์ที่ 3 กำลังการผลิต, สัปดาห์ที่ 9 การไหลของวัสดุ, สัปดาห์ที่ 11 ผังบล็อกและเส้นทาง และสัปดาห์ที่ 13 การประเมินทางเลือก

ผลลัพธ์การเรียนรู้ (Learning Outcomes): (1) แยกเวลาวิ่งไป–กลับและเวลาหยุดรถ (2) คำนวณรอบขนถ่ายเต็มต่อวัน (3) หาจำนวนรถขั้นต่ำ (4) ตรวจเงื่อนไข N−1 และ N (5) ใช้โปรแกรมตรวจคำตอบด้วยมือ

ข้อจำกัด: เป็นแบบจำลองกำลังการขนถ่ายเชิงตัวเลขเพื่อการสอนเท่านั้น การใช้งานจริงต้องพิจารณาขนาดทางเดิน พื้นที่กลับรถ ความปลอดภัยทางแยก ความสามารถยกสูง น้ำหนักบรรทุกจริง และการจัดตารางเดินรถเพิ่มเติม
02 / PROBLEM STATEMENT

โจทย์ปัญหา: ต้องมีรถกี่คันจึงจะขนได้ครบ

โรงงานใช้รถขนถ่ายวัสดุไฟฟ้า (Electric Material Transport Cart) รับลังจาก จุดโหลด (Loading Station) ไปยัง จุดขนถ่ายลง (Unloading Station) แล้ววิ่งกลับเปล่าเพื่อทำรอบใหม่ โดยมีข้อมูลตั้งต้นดังนี้

ข้อมูล (Input)ค่าเริ่มต้นหน่วย (Unit)
ปริมาณ Q500ลัง/วัน
จำนวนบรรทุก q4ลัง/รอบ
ระยะทาง D / ความเร็ว Vₗ / Vₑ120 / 60 / 120เมตร / เมตรต่อนาที / เมตรต่อนาที
เวลาโหลด Tₗ / ขนลง Tᵤ2 / 1นาที/รอบ
เวลาตามกะ Hₛ / พัก B480 / 60นาที/วัน
ความพร้อมใช้งาน η80%สัดส่วน

สิ่งที่ต้องหา: เวลาต่อรอบ จำนวนรอบเต็ม/วัน กำลังต่อคัน จำนวนรถขั้นต่ำ อัตราการใช้กำลัง และการตรวจสอบเมื่อมีรถ N−1 คัน

สมมติว่าไม่มีเวลารอคิว วัสดุขนได้ไม่เกิน q ลังต่อรอบ และรอบสุดท้ายอาจบรรทุกไม่เต็มได้ ความพร้อมใช้งาน η หักเวลาสูญเสียเพิ่มเติมจากเวลาพัก ไม่ใช่การหักเวลาพักซ้ำ
03 / THEORY & EQUATIONS

ทฤษฎี สมการ และสัญลักษณ์

คำนวณจากวงรอบรถหนึ่งคันก่อน แล้วหารปริมาณที่ต้องขนด้วยกำลังขนต่อคันที่ทำได้จริง โดยนับเฉพาะรอบที่จบภายในวัน

T꜀ = D/Vₗ + D/Vₑ + Tₗ + Tᵤ
H = Hₛ − B ; Hₑ = ηH ; r = ⌊Hₑ/T꜀⌋
C₁ = r × q ; Nₘᵢₙ = ⌈Q/C₁⌉ ; U = 100Q/(NₘᵢₙC₁)
สัญลักษณ์ความหมายภาษาไทย (English Name)หน่วย
Q / qปริมาณขนย้าย / จำนวนต่อรอบ (Required Handling Quantity / Load per Trip)ลัง/วัน / ลัง/รอบ
Dระยะทางขนย้ายทางเดียว (One-way Transport Distance)เมตร
Vₗ / Vₑความเร็วขณะบรรทุก / กลับเปล่า (Loaded / Empty Travel Speed)เมตร/นาที
Tₗ / Tᵤเวลาโหลด / ขนลง (Loading / Unloading Time)นาที/รอบ
T꜀เวลารวมต่อรอบ (Vehicle Cycle Time)นาที/รอบ
Hₛ / Bเวลาตามกะ / เวลาพัก (Scheduled Shift Time / Break Time)นาที/วัน
H / η / Hₑเวลาสุทธิ / ความพร้อมใช้งาน / เวลาใช้จริง (Net Operating Time / Availability Factor / Effective Operating Time)นาที/วัน / สัดส่วน / นาที/คัน/วัน
r / C₁ / Nₘᵢₙรอบเต็มต่อคัน / กำลังขนต่อคัน / รถขั้นต่ำ (Completed Cycles / Capacity per Vehicle / Minimum Number of Vehicles)รอบ/คัน/วัน / ลัง/คัน/วัน / คัน
Uอัตราใช้กำลังการขนถ่าย (Fleet Capacity Utilization)%
⌊ ⌋ / ⌈ ⌉ปัดลง / ปัดขึ้น (Floor / Ceiling Function)จำนวนเต็ม
