ทฤษฎี สมการ และตารางสัญลักษณ์

วิธีการให้คะแนนถ่วงน้ำหนัก (Factor Rating Method: FRM) ใช้เปรียบเทียบทางเลือกจากหลายเกณฑ์ตามน้ำหนักความสำคัญ (Factor Weight) และคะแนนความเหมาะสม (Factor Rating) โดยถือว่าคะแนนแต่ละปัจจัยเปรียบเทียบและบวกชดเชยกันได้

Sⱼ = [Σᵢ₌₁ⁿ (wᵢ × rᵢⱼ)] / 100
เป้าหมาย: เลือกทำเล j ที่ให้ Sⱼ สูงที่สุด ภายใต้น้ำหนักรวม 100%

rᵢⱼคะแนนปัจจัย i สำหรับทำเล j (Factor Rating)คะแนน 1–5
Sⱼคะแนนรวมถ่วงน้ำหนักของทำเล j (Weighted Location Score)คะแนน 1–5

การคำนวณด้วยมือ (Manual Calculation)

  1. ตรวจผลรวมน้ำหนัก
    30 + 25 + 20 + 15 + 10 = 100% ✓
  2. คูณน้ำหนักกับคะแนนของแต่ละทำเล

    ตัวอย่างปัจจัยการขนส่ง ทำเล A: 30 × 5 = 150 คะแนนเปอร์เซ็นต์ (ก่อนหาร 100)

    ปัจจัยทำเล Aทำเล Bทำเล C
    การขนส่ง (Transportation)30×5 = 15030×4 = 12030×3 = 90
    แรงงาน (Labor)25×3 = 7525×5 = 12525×4 = 100
    วัตถุดิบ (Materials)20×4 = 8020×3 = 6020×5 = 100
    สาธารณูปโภค (Utilities)15×4 = 6015×4 = 6015×3 = 45
    กฎหมายและสิ่งแวดล้อม (Regulatory)10×3 = 3010×4 = 4010×5 = 50
    ผลรวมก่อนหาร 100395405385
  3. หารผลรวมด้วย 100 เพื่อหาคะแนนสุดท้าย
    SA = 395/100 = 3.95 คะแนน
    SB = 405/100 = 4.05 คะแนน
    SC = 385/100 = 3.85 คะแนน
  4. จัดอันดับและเลือกทำเล

    อันดับ 1 = ทำเล B (4.05), อันดับ 2 = ทำเล A (3.95), อันดับ 3 = ทำเล C (3.85)

คำตอบ: เลือกทำเล B เนื่องจากมีคะแนนรวมถ่วงน้ำหนักสูงสุด 4.05 คะแนน โดยคะแนนแรงงานที่สูงช่วยชดเชยคะแนนบางปัจจัยที่ต่ำกว่าทำเลอื่น

วิธีลัด (Shortcut Method)

วิธีลัดที่ 1 — คิดเลขเต็มก่อนหาร

ใช้ค่าน้ำหนัก 30, 25, 20, 15, 10 คูณคะแนนแต่ละข้อโดยตรง แล้ว หาร 100 เพียงครั้งเดียวตอนจบ แทนการแปลงเป็น 0.30, 0.25 ฯลฯ ทุกแถว

B = (120+125+60+60+40)/100 = 4.05

วิธีลัดที่ 2 — คำนวณผลต่างเทียบ A

คำนวณ A เป็นฐานก่อน จากนั้นหาส่วนต่างของ B และ C ทีละปัจจัย เพื่อลดขั้นตอนการหาผลรวมหลายชุด

ΔSB−A = (−30+50−20+0+10)/100 = +0.10
ΔSC−A = (−60+25+20−15+20)/100 = −0.10

ดังนั้น B = 3.95+0.10 = 4.05 และ C = 3.95−0.10 = 3.85 ซึ่งตรงกับวิธีปกติทุกประการ

คะแนนต่างกันเพียง 0.10–0.20 คะแนน จึงควรทดลองปรับน้ำหนัก (Sensitivity Analysis) เพื่อตรวจว่าผลการจัดอันดับเปลี่ยนง่ายหรือไม่
