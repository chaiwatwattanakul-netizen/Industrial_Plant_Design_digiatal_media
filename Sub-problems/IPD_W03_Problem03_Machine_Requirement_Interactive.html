ทฤษฎี: กำลังการผลิต (Production Capacity) และจำนวนเครื่องจักร (Machine Requirement)

H = Hs − B
q = INT(H ÷ t)
Nmin = ROUNDUP(Q ÷ q, 0)
Ctotal = Nmin × q

หลักการ: INT (Integer Function) คือฟังก์ชันปัดลงเป็นจำนวนเต็ม; ROUNDUP (Round-up Function) คือฟังก์ชันปัดขึ้น; MOD (Modulo Function) คือการหารเอาเศษ โดยแสดงชื่อไทย–อังกฤษครบทุกสัญลักษณ์ในตารางด้านบน
ความเชื่อมโยงกับบทเรียนสัปดาห์ที่ 2: สัญลักษณ์ H ใช้แทนเวลาผลิตสุทธิ (Net Available Production Time) เหมือนกันตลอดชุดโจทย์; Hₛ ใช้แทนเวลาตามกะ (Scheduled Shift Time) เพื่อไม่ให้สับสนกับ H และ ML เท่ากับ WT เฉพาะโจทย์งานหนึ่งขั้นตอนนี้
ขอบเขตโจทย์ (Assumptions): ทุกเครื่องผลิตแบบเดียวกัน งานแต่ละชิ้นต้องจบภายในวัน ไม่มีงานเสีย ไม่มีการตั้งเครื่อง หรือหยุดอื่นนอกเหนือจากเวลาพัก เมื่อใช้ในโรงงานจริงต้องเพิ่มปัจจัยเหล่านั้นด้วย

วิธีคำนวณด้วยมือทีละขั้น (Manual Calculation)

  1. หาเวลาผลิตสุทธิต่อเครื่อง
    H = Hₛ − B
  2. หากำลังผลิตต่อเครื่อง (จำนวนชิ้นเต็ม)
    q = INT(H/t)
  3. หาภาระงานรวมในหน่วยนาที
    ML = Q×t
  4. คำนวณจำนวนเครื่องขั้นต่ำ และปัดขึ้น
    N_min = ROUNDUP(Q/q,0)
  5. ตรวจว่าจำนวนเครื่องนั้นเพียงพอและน้อยกว่านี้ไม่ได้
    ตรวจสอบ (N−1) และ N เครื่อง
  6. หาอัตราการใช้กำลังผลิตและกำลังสำรอง
    U = Q/(N_min×q)
รายการผลลัพธ์จากคำนวณด้วยมือหน่วย

วิธีลัด (Capacity-slot Method)

มองกำลังผลิตต่อเครื่องเป็นจำนวนช่องสำหรับผลิตชิ้นงาน เมื่อรู้ว่าเครื่องหนึ่งผลิตได้ 42 ชิ้น/วัน ให้หารจำนวนชิ้นที่ต้องผลิต แล้วดูจำนวนชิ้นที่เหลือ

Q = a × q + r
Nmin = a + (r > 0 ? 1 : 0)

a = จำนวนเครื่องที่ผลิตเต็มกำลัง (Full-load Machines), r = จำนวนชิ้นที่เหลือ (Remainder Units); ถ้า r = 0 ไม่ต้องเพิ่มเครื่องอีก วิธีนี้เทียบเท่ากับการปัดขึ้น Q/q ทุกกรณีที่ q > 0

สูตร Excel ตามแบบฝึกหัด

=INT((Hₛ-B)/t)
=ROUNDUP(Q/q,0)

ตรวจคำตอบที่รวดเร็ว

(N−1)q < Q ≤ Nq
