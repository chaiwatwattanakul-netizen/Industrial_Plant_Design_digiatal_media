02 / Understand Distance → Choose Method

เข้าใจลักษณะการเดินทางก่อนเลือกวิธีคำนวณ

เริ่มจากรูปแบบระยะทาง แล้วจึงเลือกวิธีหาทำเลที่ตั้งโรงงาน · ภาพทั้ง 3 ใช้ต้นทาง A และปลายทาง B ตำแหน่งเดียวกัน เพื่อเปรียบเทียบได้ชัดเจน

↗
กรณีเดินทางเส้นตรง (Euclidean)

COG ใช้หาจุดเริ่มต้น → Geometric Median ใช้หาค่าต่ำสุดของระยะทางเส้นตรงรวมถ่วงน้ำหนัก

▦
กรณีถนนกริด (Rectilinear)

ใช้ Weighted Median หาค่าต่ำสุดของระยะทางตามแกน X และ Y รวมถ่วงน้ำหนัก

ทำความรู้จัก 3 วิธี — เรียงจากวิธีพื้นฐานสู่การหาค่าเหมาะสมที่สุด

วิธีที่ 1 · หาตำแหน่งเบื้องต้น

จุดศูนย์ถ่วง (Center of Gravity: COG)

↗ เส้นตรง / Euclidean · ใช้เป็นตำแหน่งประมาณ

นำพิกัดของศูนย์รวบรวมมาเฉลี่ยแบบถ่วงน้ำหนักตามปริมาณวัตถุดิบ คำนวณง่ายและเหมาะเป็นจุดตั้งต้น แต่ไม่รับประกันว่าผลรวมระยะทางเส้นตรงถ่วงน้ำหนักต่ำที่สุด

X̄ = Σ(WᵢXᵢ)/ΣWᵢ
Ȳ = Σ(WᵢYᵢ)/ΣWᵢ
รูปแบบระยะทางที่นำมาประเมินตัวอย่าง A → B : d = √(40² + 30²) = 50 กม.

ข้อเท็จจริง: COG ทำให้ ผลรวมระยะทางยุคลิดกำลังสองถ่วงน้ำหนัก ต่ำสุด ไม่ใช่ผลรวมระยะทางแบบไม่ยกกำลังสอง

วิธีที่ 2 · คำตอบดีที่สุดสำหรับถนนกริด

มัธยฐานถ่วงน้ำหนัก (Weighted Median)

▦ ถนนกริด / Rectilinear · ค่าต่ำสุด

เรียงพิกัด X และ Y แยกกัน แล้วหาพิกัดที่น้ำหนักสะสมถึงครึ่งหนึ่งของปริมาณรวม ให้ภาระขนส่งต่ำสุดสำหรับถนนแบบตารางสมบูรณ์

Min L₁ = ΣWᵢ (|X−Xᵢ| + |Y−Yᵢ|)
รูปแบบระยะทางที่เหมาะสมตัวอย่าง A → B : d = 40 + 30 = 70 กม.

เหมาะสำหรับแบบจำลองถนนที่เดินแนวนอน–แนวตั้งได้ต่อเนื่อง ไม่ได้หมายความว่าเป็นระยะทางขับรถจริงบนถนนทุกแห่ง

วิธีที่ 3 · คำตอบดีที่สุดสำหรับเส้นตรง

มัธยฐานเชิงเรขาคณิต (Geometric Median)

↗ เส้นตรง / Euclidean · ค่าต่ำสุด

ค้นหาพิกัดที่ทำให้ ผลรวมระยะทางเส้นตรงถ่วงน้ำหนักต่ำที่สุด ใช้วิธีทำซ้ำ Modified Weiszfeld โดยเริ่มจาก COG ได้

Min L₂ = ΣWᵢ √[(X−Xᵢ)²+(Y−Yᵢ)²]
รูปแบบระยะทางที่เหมาะสมตัวอย่าง A → B : d = √(40² + 30²) = 50 กม.

ผลลัพธ์อาจอยู่คนละจุดกับ COG เพราะแก้โจทย์ลด ระยะทางรวม ไม่ใช่ระยะทางกำลังสองรวม

สรุปตัวอย่างเดียวกัน: A = (0,0), B = (40,30)↗ เส้นตรง 50 กม.▦ ถนนกริด 70 กม.ความแตกต่างมาจากวิธีวัดระยะทาง ไม่ใช่พิกัดต้นทางหรือปลายทาง
🚚

เส้นทางขนส่งจริง (Actual Road / Shipping / Air Network)

การขนส่งจริงอาจมีถนนไม่เป็นกริด เส้นทางอ้อม สิ่งกีดขวาง ชายฝั่ง ร่องน้ำ และข้อจำกัดด้านการบิน จึงต้องใช้ ข้อมูลโครงข่ายเส้นทางจริง (Routing / Network Distance) ประเมินเพิ่มเติม ไม่ควรนำระยะทางจำลองทั้งสองแบบไปใช้แทนระยะทางขับรถหรือเดินเรือโดยตรง

เหตุใด Weighted Median จึงเหมาะกับถนนกริด แต่ Geometric Median เหมาะกับเส้นตรง?
ผลรวมระยะทาง Rectilinear แยกเป็น ΣWᵢ|X−Xᵢ| + ΣWᵢ|Y−Yᵢ| ได้ จึงแก้แต่ละแกนด้วยมัธยฐานถ่วงน้ำหนักอย่างอิสระ ส่วน Euclidean มี √[(X−Xᵢ)²+(Y−Yᵢ)²] ทำให้แกน X และ Y สัมพันธ์กัน ต้องหาจุดต่ำสุดร่วมกันด้วย Geometric Median · ทั้งสองวิธีตั้งอยู่บนสมมติฐานว่าสามารถเลือกตำแหน่งโรงงานได้อิสระบนระนาบ

06 / Engineering Decision

บทวิเคราะห์และข้อเสนอแนะในการเลือกทำเล

ข้อเสนอแนะและเหตุผลจะเปลี่ยนตามระยะทางที่เลือก พร้อมตรวจสอบความเหมาะสมเชิงวิศวกรรม

เงื่อนไขก่อนนำผลไปใช้ก่อสร้างจริง

การหาตำแหน่งบนถนนจริง: ต้องทราบพิกัดภูมิศาสตร์ของศูนย์รวบรวมทั้งหมดและใช้ข้อมูลโครงข่ายถนน (Road Network) เพื่อคำนวณระยะทางขับขี่จริง รวมถึงเลือกตำแหน่งที่ก่อสร้างโรงงานได้จริง ไม่ควรนำพิกัดจำลอง (X,Y) ไปถือเป็นพิกัด GPS
ปัจจัยเพิ่มเติม: ราคาที่ดิน น้ำท่วม สาธารณูปโภค การเข้าถึงทางหลวง ระยะเวลาขนส่ง รถบรรทุกหนัก กฎหมายผังเมือง ต้นทุนลงทุน และการเติบโตของปริมาณวัตถุดิบ เป็นเงื่อนไขที่ยังไม่ได้อยู่ในตัวแบบนี้
