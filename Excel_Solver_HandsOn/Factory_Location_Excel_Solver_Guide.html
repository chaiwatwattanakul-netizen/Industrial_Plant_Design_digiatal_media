บทที่ 3

เริ่มจากศูนย์: ไม่มีไฟล์ Excel เลย

  1. เปิด Microsoft Excel บนคอมพิวเตอร์ (ควรใช้ Excel เดสก์ท็อป Windows) เลือก Blank Workbook ไม่ใช้ Excel บนเว็บสำหรับฝึก Solver Add-in
  2. บันทึกไฟล์: File → Save As → Browse → เลือกโฟลเดอร์ → ตั้งชื่อ Factory_Location_Solver.xlsx → Save
  3. เพิ่ม Worksheet ด้วยเครื่องหมาย + ให้มีทั้งหมด 5 แผ่น เปลี่ยนชื่อโดยดับเบิลคลิกที่แท็บให้เป็น ข้อมูลโจทย์, ทำเล_ค, ทำเล_ง, ทำเล_จ, สรุปผล
  4. จัดรูปแบบ: เลือกเซลล์ต้นทุนและปริมาณ → Home → Number → Comma Style หรือ Number (0 decimal places) และเพิ่มเส้นขอบหัวตาราง
ตรวจสอบ: ชื่อไฟล์ลงท้าย .xlsx และเห็นแท็บครบทั้งห้า ก่อนเข้าสู่บทถัดไป
บทที่ 4

เปิดใช้ Solver Add-in ก่อนทำแบบจำลอง

  1. คลิกเมนู File → Options (ตัวเลือก)
  2. เลือก Add-ins แล้วดูช่อง Manage ด้านล่าง เลือก Excel Add-ins และคลิก Go…
  3. ในหน้าต่าง Add-Ins ให้ทำเครื่องหมายที่ Solver Add-in → OK
  4. กลับสู่สมุดงาน เปิดแท็บ Data → มองหาปุ่ม Solver ภายใต้กลุ่ม Analysis
หากไม่พบ Solver: ปิดเปิด Excel ใหม่และตรวจ Add-ins อีกครั้ง หากไม่มีในรายการอาจต้องเลือก Browse หรือดำเนินการติดตั้งที่ Excel แจ้ง ตามคำแนะนำของ Microsoft สำหรับ Mac เส้นทางเปิด Add-in ต่างจาก Windows ส่วน Excel for the web ไม่รองรับ Solver Add-in แบบเดสก์ท็อป

อ้างอิง: Microsoft Support — Load the Solver Add-in in Excel

บทที่ 6

สร้างตัวแปรตัดสินใจ xᵢⱼ และตรวจสอบปริมาณ

ตัวแปร xᵢⱼ คือจำนวนสินค้าที่ส่งจากโรงงาน i ไปยังลูกค้า j หน่วยเป็น หน่วย/สัปดาห์ ในหนึ่งสถานการณ์มีโรงงาน 3 แห่ง × ลูกค้า 5 ราย จึงมีตัวแปรขนส่ง 15 ตัว

  1. สร้างหัวแถว 18: A18 = โรงงาน, B18:F18 = ด. ต. ถ. ท. ธ.; G18 = รวมส่ง, H18 = Cap., I18 = เหลือ
  2. สร้างชื่อโรงงานด้วยสูตร A19 = A6, A20 = A7, A21 = A8 แล้วป้อนค่า 0 ใน B19:F21 ทุกเซลล์ (นี่คือช่วงที่ Solver จะปรับ)
  3. กรอก G19 = SUM(B19:F19) แล้วคัดลอกลง G20:G21
  4. กรอก H19 = G6 แล้วคัดลอกลง H20:H21; กรอก I19 = H19-G19 แล้วคัดลอกลง
  5. กรอก B22 = SUM(B19:B21) แล้วคัดลอกขวาไป F22
  6. กรอก B23 = B9 แล้วคัดลอกขวาไป F23
  7. กรอกค่า 0 ใน B24:F24 (แถวขาดส่ง)
  8. กรอก B25 = B22+B24 แล้วคัดลอกไป F25
ความหมายสำคัญ: กรณี ค. และ จ. ต้อง ไม่มีขาดส่ง (กำหนด B24:F24 = 0) ส่วนกรณี ง. ต้องเพิ่ม B24:F24 เป็นตัวแปรที่ Solver เปลี่ยนได้ พร้อมค่าปรับขาดส่ง
บทที่ 7

กำหนดฟังก์ชันวัตถุประสงค์แบบ Linear Programming

Minimize  Z = ∑i∑j(pᵢ + tᵢⱼ)xᵢⱼ + 500∑juⱼ

โดย pᵢ คือค่าผลิตต่อหน่วย, tᵢⱼ คือต้นทุนขนส่งต่อหน่วย, xᵢⱼ คือปริมาณส่งสินค้า และ uⱼ คือขาดส่งของลูกค้า j; ค่าปรับ 500 บาท/หน่วยใช้เฉพาะกรณีศึกษาเปรียบเทียบ มิใช่ค่าปรับตามกฎหมายหรือค่าที่เกิดจริง

เซลล์ความหมายสูตร Excel (พิมพ์เครื่องหมาย = ด้วย)
G26ปริมาณขาดส่งรวม=SUM(B24:F24)
G27ปริมาณขนส่งจริงรวม=SUM(G19:G21)
G30ต้นทุนผลิตรวมกับขนส่ง=SUMPRODUCT(B13:F15,B19:F21)
G31ต้นทุนผลิตรวม=SUMPRODUCT(H6:H8,G19:G21)
G32ต้นทุนขนส่งรวม=G30-G31
G33ค่าปรับขาดส่ง=500*SUM(B24:F24)
G34ต้นทุนรวมสำหรับการตัดสินใจ=G30+G33
ตรวจสอบ: G30=G31+G32 และ G34=G30+G33; ช่วง B13:F15 และ B19:F21 เป็นตารางขนาด 3 × 5 เท่ากัน
บทที่ 8

กำหนดข้อจำกัดให้ครบทุกประเภท

∑j xᵢⱼ ≤ Sᵢ    |    ∑i xᵢⱼ + uⱼ = Dⱼ    |    xᵢⱼ, uⱼ ≥ 0

Sᵢ คือกำลังผลิตของโรงงาน i และ Dⱼ คือความต้องการลูกค้า j

ข้อจำกัด Solverช่วงเซลล์ซ้ายเครื่องหมายช่วงขวา
ยอดส่งไม่เกินกำลังผลิต$G$19:$G$21≤$H$19:$H$21
ส่งจริง + ขาดส่ง = ความต้องการ$B$25:$F$25=$B$23:$F$23
จำนวนส่งไม่ติดลบ$B$19:$F$21≥0
ขาดส่งไม่ติดลบ (เฉพาะ ง.)$B$24:$F$24≥0
ขาดส่งต้องเป็นศูนย์ (ค./จ.)$B$24:$F$24=0

หมายเหตุเรื่องสัญลักษณ์: ใน Excel Solver ให้เลือกความสัมพันธ์ = สำหรับเงื่อนไขแถว B25:F25 เท่ากับ B23:F23 (เครื่องหมาย = ไม่ใช่เครื่องหมาย ≥)

ข้อผิดพลาดที่พบบ่อย: หากกำลังผลิตรวมน้อยกว่า 68,000 แต่บังคับ u=0 และต้องส่งให้ครบทุกคน จะเป็นแบบจำลองที่ ไม่มีคำตอบที่เป็นไปได้ (Infeasible) ไม่ใช่ปัญหาที่ Excel ทำงานผิด
บทที่ 9

ตั้งค่า Solver Parameters และกด Solve

  1. เปิดแผ่นงาน ทำเล_ค คลิก Data → Solver
  2. Set Objective: เลือก $G$34 เป็นเซลล์ต้นทุนประเมินรวม
  3. To: เลือกปุ่ม Min เพราะต้องการต้นทุนต่ำสุด
  4. By Changing Variable Cells: กรอก $B$19:$F$21 (15 เซลล์)
  5. กด Add ใส่ข้อจำกัด $G$19:$G$21 <= $H$19:$H$21
  6. ใส่ข้อจำกัด $B$25:$F$25 = $B$23:$F$23
  7. ตรวจเงื่อนไขตัวแปรไม่ติดลบ และกำหนด $B$24:$F$24 = 0 สำหรับกรณี ค. และ จ.
  8. Select a Solving Method: เลือก Simplex LP
  9. ตรวจทุกค่าแล้วคลิก Solve
  10. หน้าต่าง Solver Results เลือก Keep Solver Solution แล้ว OK
หลัง Solve ตรวจ G34 และตาราง B19:F21; หากระบบรายงาน Infeasible ต้องย้อนตรวจข้อจำกัดก่อน ไม่ควรฝืนใช้คำตอบที่ไม่เป็นไปได้

อ้างอิง: Microsoft Support — Define and solve a problem by using Solver

บทที่ 12

วิเคราะห์ผลเชิงวิศวกรรม ไม่ใช่ดูตัวเลขอย่างเดียว

1. ต้นทุนผลิตถูก ≠ ทำเลดีที่สุด

โรงงาน ง. มีต้นทุนผลิต 70 บาท/หน่วย ต่ำสุดในสามทำเล แต่กำลังผลิตรวมไม่พอสำหรับส่งลูกค้าครบ ขณะที่ จ. มีต้นทุนรวมต่ำที่สุดในสองทางเลือกที่ตอบสนองความต้องการได้ครบ

2. กำลังผลิตเหลือ ≠ สูญเปล่าเสมอไป

ทำเล จ. มีกำลังผลิตรวม 70,000 และใช้ 68,000 จึงเหลือ 2,000 หน่วย สะท้อนความยืดหยุ่นรองรับคำสั่งซื้อเพิ่ม แม้ความคุ้มค่าจริงยังต้องคิดต้นทุนคงที่และเงินลงทุน

3. ความไวต่อความต้องการ

หากความต้องการทุกลูกค้าเพิ่ม 10% จะเป็น 74,800 หน่วยต่อสัปดาห์ ทำให้ทุกทางเลือกขาดกำลังผลิต: ค. ขาดอย่างน้อย 6,800; ง. ขาด 8,800; จ. ขาด 4,800 หน่วย ต้องเพิ่มกำลังผลิตหรือยอมให้มีขาดส่ง

4. ข้อจำกัดของแบบจำลอง

แบบจำลองนี้ไม่รวมค่าซื้อที่ดิน ก่อสร้าง สาธารณูปโภค ภาษี ค่าแรง ความเสี่ยงซัพพลายเชน และต้นทุนคงที่ ดังนั้น “ดีที่สุด” หมายถึงเฉพาะเกณฑ์ที่นำมาคำนวณ ไม่ใช่คำตอบการลงทุนสุดท้าย

แบบฝึกหัด Sensitivity Analysis

ทดลองเพิ่มความต้องการที่ B9:F9 ขึ้น 10% แล้วกด Solve ใหม่ เมื่อทั้งสามทำเลมีกำลังผลิตไม่พอ ต้องเปิดใช้ตัวแปรขาดส่ง B24:F24 สำหรับแต่ละกรณี และแยกผล “ยอดส่งจริง/ขาดส่ง/ค่าปรับ” อย่างชัดเจน

ข้อควรคิด: หากค่าปรับขาดส่งเปลี่ยนจาก 500 เป็นค่าอื่น คำตอบการจัดสรรสินค้าและอันดับทำเลอาจเปลี่ยน โดยเฉพาะเมื่อค่าปรับต่ำจนยอมขาดส่งได้คุ้มกว่าขนส่งบางเส้นทาง
บทที่ 13

ตัวอย่างบทสรุปรายงานวิศวกรรม

เรื่อง การเลือกทำเลที่ตั้งโรงงานผลิตชิ้นส่วนยานยนต์ไฟฟ้าด้วย Excel Solver

วัตถุประสงค์: เพื่อเลือกทำเลโรงงานแห่งใหม่หนึ่งแห่งจากทางเลือก ค. ง. และ จ. โดยให้ต้นทุนผลิตและต้นทุนขนส่งต่ำที่สุดภายใต้ข้อจำกัดกำลังผลิตและความต้องการของลูกค้า

วิธีดำเนินการ: สร้างแบบจำลอง Transportation Problem ในรูปแบบ Linear Programming ใช้ตัวแปร xᵢⱼ แทนปริมาณขนส่งและประยุกต์ Excel Solver วิธี Simplex LP กรณีที่กำลังผลิตไม่เพียงพอเพิ่มตัวแปรขาดส่งพร้อมค่าปรับ 500 บาทต่อหน่วยเพื่อใช้ประเมินทางเลือก

ผลการศึกษา: ทำเล ค. มีต้นทุน 5,667,000 บาท/สัปดาห์ และส่งสินค้าได้ครบ ทำเล ง. มีต้นทุนประเมิน 6,407,000 บาท/สัปดาห์ โดยขาดส่ง 2,000 หน่วย ส่วนทำเล จ. มีต้นทุนต่ำสุด 5,631,000 บาท/สัปดาห์ ส่งครบและมีกำลังผลิตเหลือ 2,000 หน่วย

ข้อสรุป: ภายใต้สมมติฐานและข้อมูลที่ศึกษา ควรพิจารณาเลือกทำเล จ. เนื่องจากประหยัดกว่าทำเล ค. 36,000 บาท/สัปดาห์ หรือประมาณ 1,872,000 บาทต่อปี หากดำเนินงาน 52 สัปดาห์ และคงเงื่อนไขเดิมตลอดปี

ข้อเสนอแนะ: ก่อนตัดสินใจลงทุนจริง ต้องประเมินเงินลงทุน ค่าก่อสร้าง ต้นทุนคงที่ ระยะเวลาคืนทุน ความเสี่ยงและการเติบโตของความต้องการเพิ่มเติม
