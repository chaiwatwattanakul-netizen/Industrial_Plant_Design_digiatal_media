CASE STORY · ก่อนเริ่มคำนวณ

โรงงานของเรากำลังเจอปัญหาอะไร?

โรงงานผลิตชิ้นส่วน CNC มีอาคารขนาด 30 × 20 เมตร และมี 6 แผนก เมื่อปริมาณงานเพิ่มขึ้น CNC Milling และ CNC Lathe ต้องการพื้นที่ทำงานมากขึ้น แต่โรงงานยังไม่มีแผนขยายอาคาร

ในขณะเดียวกัน คลังวัตถุดิบและคลังสินค้าสำเร็จรูปอาจจัดระบบการเก็บให้กระชับขึ้นได้บางส่วน แต่ลดพื้นที่จนต่ำกว่าขั้นต่ำที่จำเป็นไม่ได้ นอกจากนี้ทางเดินและพื้นที่สนับสนุนต้องยังคงอยู่

โจทย์ที่ผู้จัดการต้องตอบ: “จะปรับแบ่งพื้นที่ให้ทั้ง 6 แผนกอย่างไร ให้เกิดคะแนนประโยชน์รวมสูงที่สุด โดยทุกแผนกยังทำงานได้และไม่กินพื้นที่ทางเดิน?”

สถานการณ์และคะแนนประโยชน์ในบทนี้เป็นกรณีศึกษาสมมุติเพื่อการเรียนการสอน ไม่ใช่ข้อมูลโรงงานจริง

WHAT WE WANT · เป้าหมาย

โรงงานต้องการอะไร และ Solver จะช่วยเรื่องไหน?

สิ่งที่เราต้องการ

สิ่งที่โจทย์นี้ยังไม่ได้ตัดสินใจ

คำตอบที่ต้องการจาก Solver: ตัวเลข 6 ค่า ว่าแต่ละแผนกควรได้รับพื้นที่กี่ ตารางเมตร ไม่ใช่ตำแหน่งวางแผนก

โรงงานผลิตชิ้นส่วนโลหะด้วย CNC มีพื้นที่อาคาร 600 ตร.ม. และ 6 แผนก ผู้บริหารพบว่าพื้นที่คลังสินค้ามาก ขณะที่พื้นที่สำหรับเครื่องกัด/กลึง CNC จำกัด จึงต้องปรับการกระจายพื้นที่ โดยยังเหลือทางเดินหลักและพื้นที่สนับสนุนที่จำเป็น

แผนกและหน้าที่งาน

แผนกบทบาทในโรงงานข้อคำนึงสำคัญ

แผนกกลึง CNC (CNC Lathe)กลึงชิ้นงานเครื่องกลึง พื้นที่ดูแลเครื่องและการตั้งงาน

2.5 ข้อจำกัดทั้งหมดของระดับที่ 1

ข้อจำกัดความหมายที่ต้องปฏิบัติตาม
พื้นที่สุทธิพื้นที่แผนกเดิม 6 แผนกรวมกันต้องไม่เกิน 420 ตร.ม.
พื้นที่ขั้นต่ำทุกแผนกต้องมีพื้นที่อย่างน้อยตามค่าขั้นต่ำของแผนกนั้น
พื้นที่สูงสุดห้ามจัดพื้นที่ให้แผนกใดเกินเพดานสูงสุดของแผนกนั้น
พื้นที่ทางเดินและสนับสนุนต้องสงวนพื้นที่ 80 + 100 ตร.ม. ไว้ ไม่ใช้ซ้ำกับพื้นที่แผนก

ปริมาณพื้นที่พื้นที่ที่จัดสรรต้องไม่ติดลบ; แบบจำลอง LP อนุญาตให้เป็นค่าต่อเนื่อง
ผังทางเรขาคณิตผล Solver บอกขนาดพื้นที่ ไม่ได้รับประกันว่า Block Layout วางได้จริง

2.6 สมมุติฐานที่ใช้ในแบบจำลอง

  • พื้นที่อาคารรวม 600 ตร.ม. และไม่ขยายอาคารในช่วงตัดสินใจ
  • พื้นที่สุทธิให้ 6 แผนกคือ 420 ตร.ม. โดยสงวนพื้นที่ทางเดิน 80 ตร.ม. และพื้นที่สนับสนุน 100 ตร.ม. ไว้แล้ว
  • ทุกแผนกต้องเปิดดำเนินงาน และกำหนด Min–Max จากข้อมูลจำลอง ไม่ใช่ค่าที่ Solver คิดขึ้นเอง
  • คะแนนประโยชน์ต่อตารางเมตรเป็นค่าคงที่ ภายใต้โจทย์นี้ใช้เกณฑ์เดียวกันทั้ง 6 แผนก
  • พื้นที่เป็นตัวแปรต่อเนื่องใน LP; การสร้าง Block Layout ตาม Grid 1 × 1 เมตรต้องตรวจรูปทรงและพิกัดอีกครั้ง
  • พื้นที่ทางเดินหลักไม่ถูกนับซ้ำกับพื้นที่แผนก และต้องตรวจระยะปลอดภัยจริงก่อนใช้งานโรงงานจริง

2.7 สิ่งที่นักศึกษาต้องคำนวณหา

  1. พื้นที่ที่เหมาะสม (m²) ของแต่ละแผนกเดิมทั้ง 6 แผนก
  2. คะแนนประโยชน์รวมสูงที่สุด ภายใต้ข้อจำกัดที่กำหนด
  3. ตรวจพื้นที่รวม ขั้นต่ำ–สูงสุด และพื้นที่คงเหลือว่าผ่านหรือไม่
  4. เปรียบเทียบคะแนนของแผนเดิมกับผลที่ Excel Solver คำนวณ
  5. นำผลพื้นที่ไปสร้างและตรวจ Block Layout แบบ True-Scale Grid โดยแยกผล LP ออกจากการยืนยันผัง

ตัวเลข Min และ Max มาจากไหน?

Min = พื้นที่ขั้นต่ำ

พื้นที่จำเป็นสำหรับเครื่องจักร คนทำงาน พักวัสดุ และซ่อมบำรุง โดยต้องไม่ซ้ำกับทางเดินหลักที่กันไว้แล้ว

Max = พื้นที่สูงสุด

เพดานพื้นที่ที่อนุญาตในแผนงาน เช่น พื้นที่ขั้นต่ำบวกส่วนเผื่อขยาย/พื้นที่ที่คาดว่าจะใช้ประโยชน์ได้

17.7 สมมุติฐานของโจทย์

  • พื้นที่อาคารรวม 600 m² และพื้นที่สุทธิสำหรับแผนกเดิมและใหม่รวมกันไม่เกิน 420 m²
  • ทั้ง 6 แผนกเดิมยังเปิดดำเนินงานและพื้นที่แต่ละแผนกต้องอยู่ระหว่าง Min–Max
  • แผนกใหม่ที่เลือกเปิดต้องมีพื้นที่อย่างน้อย Min และไม่เกิน Max; แผนกที่ไม่เลือกเปิดต้องเป็น 0 m²
  • เปิดแผนกใหม่อย่างน้อย 2 แต่ไม่เกิน 3 แผนก; สถานะเปิดแต่ละแผนกเป็น Binary 0/1
  • คะแนนเป็นคะแนนประโยชน์ต่อตารางเมตรสมมุติ ไม่ใช่เงินบาท และใช้เกณฑ์เดียวกันใน 9 แผนก
  • ใช้ตัวแปรพื้นที่แบบต่อเนื่อง ส่วนการยืนยันผังและการเข้าถึงแผนกต้องตรวจแยกหลังการหาคำตอบ
  • ยังไม่ได้รวมงบลงทุนและผลตอบแทนทางการเงินจากการสร้างแผนกใหม่ในแบบจำลองนี้

17.8 สิ่งที่นักศึกษาต้องคำนวณหา

  1. ควรสร้างแผนกใหม่ใดบ้าง (ค่า Binary ของทั้ง 3 ทางเลือก)
  2. ควรจัดพื้นที่กี่ตารางเมตรให้แผนกเดิมและแผนกใหม่แต่ละแห่ง
  3. คะแนนประโยชน์รวมสูงสุดภายใต้นโยบายสร้าง 2–3 แผนก
  4. ตรวจพื้นที่รวม ขอบเขตพื้นที่ สถานะ Binary และจำนวนแผนกที่เปิด
  5. เปรียบเทียบคะแนนและผลการเลือกแผนกกับระดับที่ 1 และทางเลือกอื่น
  6. แสดงผัง Block Layout ที่สอดคล้องกับผลที่ได้รับ พร้อมตรวจ Geometry โดยไม่อ้างว่า LP/MILP หาพิกัดดีที่สุดแล้ว

ก่อนสร้างสมการ ให้แปลง กติกาของผู้บริหาร เป็นประโยคสั้น ๆ ที่ตรวจได้จริง แล้วจึงจับคู่กับ Constraint ใน Solver

ข้อจำกัดอธิบายภาษาธรรมดาตรวจอย่างไร
พื้นที่รวมรวมพื้นที่ทุกแผนกต้องไม่เกิน 420 m²SUM พื้นที่ ≤ 420
แผนกเดิม 6 แผนกต้องเปิดต่อทุกแผนก และพื้นที่อยู่ในช่วง Min–MaxLᵢ ≤ aᵢ ≤ Uᵢ
แผนกใหม่ที่เปิดถ้าเลือกสร้างต้องมีพื้นที่อย่างน้อย Min แต่ไม่เกิน MaxLⱼyⱼ ≤ xⱼ ≤ Uⱼyⱼ
แผนกใหม่ที่ไม่เปิดถ้าไม่สร้าง พื้นที่จัดสรรต้องเป็นศูนย์เมื่อ yⱼ=0 ⇒ xⱼ=0
จำนวนแผนกใหม่นโยบายกำหนดให้สร้างอย่างน้อย 2 แผนก แต่ไม่เกิน 32 ≤ Σyⱼ ≤ 3
Binaryค่าการเปิดแผนกต้องเป็น 0 หรือ 1 เท่านั้นyⱼ ∈ {0,1}
พื้นที่ไม่ติดลบไม่มีค่าพื้นที่เป็นลบaᵢ,xⱼ ≥ 0

ทำความเข้าใจ Binary Variable: 0 หรือ 1

0 = ไม่สร้าง

เช่น Maintenance ไม่ถูกเลือก ⇒ พื้นที่ Maintenance = 0 m² แม้ข้อมูล Min จะเท่ากับ 25

1 = สร้าง

เช่น Maintenance ถูกเลือก ⇒ ต้องจัดพื้นที่ตั้งแต่ 25 ถึง 35 m²

ตัวอย่าง Maintenance: 25 × y₁ ≤ x₁ ≤ 35 × y₁

เมื่อ y₁ = 0 จะได้ 0 ≤ x₁ ≤ 0; เมื่อ y₁ = 1 จะได้ 25 ≤ x₁ ≤ 35 เงื่อนไขทั้งสองเป็นเชิงเส้นเมื่อข้อมูล Min/Max เป็นค่าคงที่

ตรวจความเป็นไปได้: ถ้าสร้าง 3 แผนกพร้อมกัน ใช้พื้นที่ขั้นต่ำครบ 420 m² จึงไม่มีพื้นที่เหลือขยายแผนกเดิม แต่ถ้าเลือก 2 แผนก อาจมีพื้นที่เหลือให้เพิ่มกับแผนกเดิมได้
ตัวอย่างแผนที่เป็นไปได้ (Feasible) แต่ยังไม่รู้ว่าดีที่สุดหรือไม่

จัดพื้นที่ 6 แผนกเดิมตามขั้นต่ำ 355 m² แล้วสร้าง Maintenance 25 m² และ Tool Room 20 m² เหลือพื้นที่อีก 20 m² ให้เพิ่มแก่แผนกเดิมโดยไม่เกิน Max ตัวอย่างนี้ผ่านเงื่อนไขจำนวนแผนกและพื้นที่ แต่ต้องคำนวณคะแนนและเปรียบเทียบทางเลือกอื่นจึงจะทราบว่า Optimal หรือไม่

ลองวิเคราะห์ความเป็นไปได้ ก่อนสร้างสมการ

คิดก่อนคำนวณ: ถ้าสร้างทั้ง 3 แผนกในขนาดขั้นต่ำ จะมีพื้นที่พอหรือไม่?

พื้นที่ 6 แผนกเดิมขั้นต่ำ = 355; แผนกใหม่ขั้นต่ำ = 25 + 20 + 20 = 65; รวม 420 m² พอดี ทำได้ด้านปริมาณพื้นที่ แต่ยังต้องตรวจข้อจำกัดอื่นและรูปทรง Block Layout

สร้าง Mathematical Model แบบ MILP

เมื่อเข้าใจปัญหาและข้อจำกัดแล้ว จึงกำหนดตัวแปรและสร้างแบบจำลอง Mixed-Integer Linear Programming (MILP) โดยใช้ตัวแปรพื้นที่แบบต่อเนื่องร่วมกับตัวแปรเปิดแผนกแบบไบนารี

1. ตัวแปรตัดสินใจ (Decision Variables)

สัญลักษณ์ความหมายหน่วย / ช่วงค่า
aᵢ (i=1…6)พื้นที่ 6 แผนกเดิมm² ต่อเนื่อง; ต้องอยู่ระหว่าง Min และ Max
xⱼ (j=1…3)พื้นที่ 3 แผนกใหม่m² ต่อเนื่อง ≥ 0
yⱼ (j=1…3)สถานะการเปิดแผนกใหม่Binary: 0 หรือ 1

2. เป้าหมาย (Objective)

Maximize Z = 3a₁ + 7a₂ + 9a₃ + 5a₄ + 4a₅ + 2a₆ + 8x₁ + 7x₂ + 6x₃

ทุกสัมประสิทธิ์คือคะแนนประโยชน์ต่อ 1 m² ไม่มีการนำคะแนนไปบวกรวมกับเงินบาทโดยตรง

3. ข้อจำกัด (Constraints)

(ก) Σaᵢ + Σxⱼ ≤ 420 m²
(ข) Lᵢ ≤ aᵢ ≤ Uᵢ สำหรับแผนกเดิม 6 แผนก
(ค) 25y₁ ≤ x₁ ≤ 35y₁ (Maintenance)
(ง) 20y₂ ≤ x₂ ≤ 30y₂ (Tool Room)
(จ) 20y₃ ≤ x₃ ≤ 30y₃ (Metrology Lab)
(ฉ) 2 ≤ y₁+y₂+y₃ ≤ 3
(ช) yⱼ ∈ {0,1}; aᵢ,xⱼ ≥ 0
ทำไมยังเลือก Simplex LP ในหน้าต่าง Solver?

เพราะ Objective และ Constraints ยังเป็น เชิงเส้น ส่วนข้อจำกัด Binary ทำให้ Solver ต้องค้นหาคำตอบจำนวนเต็มร่วมด้วย ไม่ใช่แก้ LP แบบต่อเนื่องอย่างเดียว

โจทย์ A — บังคับสร้างครบ 3 แผนก (ดูแนวทำ)

โจทย์ B — สร้างได้ไม่เกิน 3 แผนก (ไม่บังคับสร้าง) (ดูแนวทำ)

แก้ “แผนกใหม่ขั้นต่ำ” เป็น 0 แล้วกด Optimize ด้วยข้อมูลเดิม ผลที่เหมาะสมคือเลือกสร้าง Maintenance เพียง 1 แผนก (25 ตร.ม.) และขยาย CNC Milling อีก 40 ตร.ม. ได้ 2,545 คะแนน ส่วนการไม่สร้างเลยได้ 2,520 คะแนน จึงไม่ใช่คำตอบดีที่สุดของนโยบายใหม่นี้

โจทย์ C — ลดพื้นที่สุทธิจน Infeasible (ดูแนวทำ)

ลดพื้นที่อาคารหรือเพิ่มพื้นที่สนับสนุนจนพื้นที่สุทธิน้อยกว่าผลรวม Min ของ 6 แผนกเดิมและ Min ของแผนกใหม่ที่ถูกบังคับเลือก 2 แผนก จากนั้นกด Optimize ระบบต้องแจ้งว่าไม่พบทางเลือกที่เป็นไปได้
