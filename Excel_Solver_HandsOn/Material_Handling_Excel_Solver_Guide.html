บทที่ 01 · เริ่มจากปัญหาจริง

ความรู้พื้นฐานเกี่ยวกับระบบขนถ่ายวัสดุ

ระบบขนถ่ายวัสดุ (Material Handling System) คือการเคลื่อนย้าย จัดเก็บ และควบคุมวัสดุระหว่างจุดต่าง ๆ ภายในโรงงาน การออกแบบผังที่ดีช่วยลดระยะทาง ส่วนการจัดสรรงานขนถ่ายที่ดีช่วยเลือก อุปกรณ์และปริมาณงานให้เหมาะสม ภายใต้ความสามารถและข้อจำกัดความปลอดภัย

ปัญหาทางกายภาพ

ตำแหน่งแผนก จุดรับ–ส่ง ทางเดิน ความกว้าง ความยาวและสิ่งกีดขวาง เป็นข้อมูลมาจากผังโรงงาน

หากแท็บ Data ยังไม่พบปุ่ม Solver ให้เปิด Add-in ก่อน โดยใช้ Excel รุ่นติดตั้งบนคอมพิวเตอร์ (Excel for Windows) ไม่ใช่ Excel บนเว็บหรือโทรศัพท์

  1. เลือก File → Options
  2. เลือก Add-ins และตรง Manage เลือก Excel Add-ins

บทที่ 12 · เครื่องมือ Interactive HTML

ทดลองเปลี่ยนเงื่อนไขและวิเคราะห์ความไว

เครื่องมือนี้เป็น ตัวแก้ปัญหาเชิงเส้นที่ทำงานด้วย JavaScript ภายในไฟล์ HTML ไม่ได้เรียก Excel Solver โดยตรง แต่ให้คำตอบจากแบบจำลองเดียวกันสำหรับกรณี 3 เส้นทางและ 2 อุปกรณ์ เพื่อให้นักศึกษาทดลองก่อนนำข้อมูลไปกรอกใน Excel

ระบบจะตรวจคำตอบที่เป็นไปได้โดยใช้การจัดสรรแบบต้นทุนต่ำสุด (Minimum-Cost Flow) ซึ่งเป็นรูปแบบที่เทียบเท่า Linear Programming สำหรับโจทย์นี้ ค่าตัวแปรเป็นจำนวนจริงไม่ติดลบ หากต้องใช้พาเลทจำนวนเต็มให้เพิ่มข้อกำหนด Integer ใน Excel ตามความเหมาะสม

ทดลองเปลี่ยนโจทย์และกดคำนวณ

บทที่ 13 · เขียนเหตุผล ไม่ใช่บอกตัวเลขอย่างเดียว

รายงานที่ดีควรอธิบายสถานการณ์ วิธีการ ข้อจำกัด ผลคำนวณ และผลกระทบจริงในรูปแบบที่ตรวจสอบย้อนหลังได้ ไม่จำเป็นต้องเขียนสมการซับซ้อนเพิ่มเติม แต่ต้องอ้างตัวเลขและหน่วยอย่างถูกต้อง

ตัวอย่างบทสรุปสำหรับข้อมูลเริ่มต้น

การศึกษานี้วิเคราะห์ต้นทุนขนถ่ายวัสดุภายในโรงงาน CNC ขนาด 30 × 20 เมตร โดยกำหนด 3 เส้นทางที่มีความต้องการรวม 120 พาเลท/วัน ใช้ Microsoft Excel Solver วิธี Simplex LP เพื่อจัดสรรปริมาณงานระหว่าง Forklift และ Hand Pallet Truck ภายใต้ข้อจำกัดกำลังขนถ่ายและข้อจำกัดเส้นทาง R2 ซึ่งไม่อนุญาตให้ใช้ Hand Pallet

แผนที่เหมาะสมที่สุดให้ Forklift ขนย้าย 70 พาเลท/วัน และ Hand Pallet 50 พาเลท/วัน ต้นทุนรวม 1,776 บาท/วัน ลดลงจากแผนเดิมที่ 2,124 บาท/วัน เป็นเงิน 348 บาท/วัน หรือ 16.38% โดยยังขนย้ายครบทุกเส้นทาง ไม่เกินกำลังอุปกรณ์และไม่เปลี่ยนตำแหน่งแผนก

ข้อจำกัดที่ควรศึกษาต่อ ได้แก่ เวลารอบรถขนถ่าย ความเร็วและจุดตัดทางเดิน น้ำหนักบรรทุกจริง การรอคิว การจราจรภายในโรงงาน และความสามารถสุทธิที่เปลี่ยนตามระยะทาง

ข้อสังเกตด้านทรัพยากร

Hand Pallet ใช้เต็มกำลัง 50/50 พาเลท ขณะที่ Forklift ใช้ 70/90 พาเลท เหลือ 20 พาเลท/วัน สะท้อนว่า ต้นทุนที่ดีที่สุดไม่ได้บังคับใช้ทุกอุปกรณ์เต็มกำลัง และคำตอบอาจเปลี่ยนหากต้นทุน ความต้องการ หรือเงื่อนไขความปลอดภัยเปลี่ยนไป

หากนักศึกษานำชุดทดสอบ Interactive ไปใช้ทำรายงาน ต้องเขียนบทสรุปใหม่ตามตัวเลขของสถานการณ์นั้น โดยไม่คัดลอกบทสรุปฐาน 1,776 บาท/วันไปใช้เมื่อข้อมูลเปลี่ยน

ดูเฉลย
