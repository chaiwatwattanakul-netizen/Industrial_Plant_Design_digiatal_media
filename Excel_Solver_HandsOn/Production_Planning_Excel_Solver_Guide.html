บทที่ 01 · เข้าใจแนวคิดก่อนอ่านโจทย์

ความรู้พื้นฐานเกี่ยวกับการวางแผนการผลิต

การวางแผนการผลิต (Production Planning) คือการกำหนดว่าในช่วงเวลาที่พิจารณา ควรผลิตสินค้าแต่ละชนิดจำนวนเท่าใด โดยคำนึงถึงความต้องการลูกค้า เครื่องจักร แรงงาน วัตถุดิบ และเป้าหมายของโรงงาน หัวข้อนี้มุ่งเน้น การเลือกส่วนผสมการผลิต (Product Mix) ของสินค้า A และ B ให้ได้กำไรรวมสูงสุด

① ตัวแปรตัดสินใจ

ตัวเลขที่ผู้จัดการยังเลือกได้ เช่น x = จำนวนสินค้า A และ y = จำนวนสินค้า B

② วัตถุประสงค์

สิ่งที่ต้องทำให้ดีที่สุด เช่น กำไรสูงสุด หรือ ต้นทุนต่ำสุด

③ ข้อจำกัด

เงื่อนไขที่ห้ามละเมิด เช่น เวลาทำงานหรือยอดสั่งซื้อสูงสุด

Linear Programming คืออะไร?

Linear Programming (LP) เป็นการหาค่าที่เหมาะสมที่สุด โดยฟังก์ชันวัตถุประสงค์และข้อจำกัดต้องเป็นความสัมพันธ์เชิงเส้น เช่น 2x + y ≤ 100 ในกรณีนี้ Simplex LP เหมาะสม เพราะกำไรและเวลาที่ใช้ต่อชิ้นเป็นค่าคงที่ ไม่ได้ขึ้นอยู่กับจำนวนผลิตแบบไม่เชิงเส้น

เชื่อมโยงแผนการสอน: สัปดาห์ 3 เรียนกำลังการผลิตและจำนวนเครื่องจักร สัปดาห์ 14 ฝึกซอฟต์แวร์ และสัปดาห์ 15 ประยุกต์กับกรณีศึกษาโรงงาน CNC จึงไม่จำเป็นต้องเรียนอัลกอริทึม Simplex เชิงลึก

Complete Problem Statement · Level 1 / Simplex LP
อ่านข้อมูลทั้งหมดให้จบก่อนเริ่มคำนวณ โจทย์นี้มีข้อมูลครบในบทเดียว และยังไม่มีเฉลย

2.1 สถานการณ์โรงงาน

โรงงานรับจ้างผลิตชิ้นส่วนโลหะด้วยเครื่องจักร CNC มีผลิตภัณฑ์ 2 ชนิด คือ สินค้า A และ สินค้า B ทั้งสองให้กำไรส่วนเพิ่มต่อชิ้นและใช้เวลา CNC Lathe, CNC Milling และ Inspection ไม่เท่ากัน ผู้จัดการต้องตัดสินใจว่าจะผลิตสินค้าชนิดละกี่ชิ้นในรอบการวางแผนเดียวกัน

2.2 ปัญหาที่เกิดขึ้น

เวลาเครื่องจักรมีจำกัด และไม่สามารถผลิตเกินยอดสั่งซื้อสูงสุดได้ การผลิต A มากอาจทำให้ CNC Lathe มีเวลาไม่พอ ส่วนการผลิต B มากอาจทำให้ CNC Milling เต็มกำลังก่อน จึงต้องจัดส่วนผสมการผลิต (Product Mix) ให้เหมาะสม

2.3 เป้าหมาย

เลือกจำนวนผลิตสินค้า A และ B เพื่อให้กำไรส่วนเพิ่มรวมสูงสุด ภายใต้ข้อจำกัดทั้งหมด

2.6 ข้อจำกัดของโจทย์

  1. ใช้เวลา CNC Lathe ไม่เกิน 100 ชั่วโมง
  2. ใช้เวลา CNC Milling ไม่เกิน 80 ชั่วโมง
  3. ใช้เวลา Inspection ไม่เกิน 65 ชั่วโมง
  4. ผลิต A ไม่เกิน 45 ชิ้น และ B ไม่เกิน 40 ชิ้น
  5. ผลิต A และ B ไม่ต่ำกว่าขั้นต่ำที่กำหนด (0 ชิ้น)
  6. จำนวนผลิตต้องไม่ติดลบ

2.7 สมมุติฐาน

ศึกษาหนึ่งรอบการผลิต กำไรส่วนเพิ่มและเวลาต่อชิ้นคงที่ ไม่มี Setup หรือข้อจำกัดวัตถุดิบและสินค้าคงคลังเพิ่ม ในระดับนี้ใช้ตัวแปรต่อเนื่องสำหรับสาธิต LP หากเกิดเศษชิ้นจะต้องเพิ่ม Integer Constraints ก่อนนำไปใช้จริง ข้อมูลทั้งหมดเป็นกรณีศึกษาสมมุติ

2.8 สิ่งที่ต้องการให้นักศึกษาหา

  1. จำนวนผลิต A และ B ที่เหมาะสม
  2. กำไรส่วนเพิ่มรวมสูงสุด
  3. เวลาใช้จริงและเวลาคงเหลือของทรัพยากรทั้ง 3 ประเภท
  4. สถานะผ่าน/ไม่ผ่านข้อจำกัดทุกข้อ

บทที่ 06 · Excel สำหรับผู้เริ่มต้น

เปิดใช้งาน Solver Add-in

Solver เป็น Add-in ของ Excel ไม่ใช่คำสั่งที่แสดงอยู่เสมอ ก่อนใช้งานต้องตรวจสอบว่าคำสั่ง Solver ปรากฏในแท็บ Data หรือไม่ หากไม่พบให้เปิดใช้งานตามขั้นตอนนี้

  1. ใน Excel for Windows คลิก File → Options
  2. เลือก Add-ins จากเมนูด้านซ้าย
  3. มองหาช่อง Manage ด้านล่าง เลือก Excel Add-ins แล้วคลิก Go…
  4. ในหน้าต่าง Add-ins ให้ติ๊ก Solver Add-in แล้วคลิก OK
  5. กลับไปที่แท็บ Data กลุ่ม Analysis จะพบปุ่ม Solver
ถ้าไม่พบ Solver: ตรวจสอบว่าเลือก Excel Add-ins ไม่ใช่ COM Add-ins; ถ้าไม่มีรายการ Solver ให้ใช้ Browse หรือทำตามข้อความแจ้งให้ติดตั้งจาก Microsoft; หากใช้งาน Excel บนเว็บ จะไม่สามารถเรียก Solver Add-in แบบ Desktop ได้ ให้เปิดไฟล์ใน Excel สำหรับคอมพิวเตอร์

บทที่ 14 · รายงานและตีความผล

Machine Utilization และบทสรุปเชิงวิศวกรรม

ผลลัพธ์ที่นักศึกษาได้รับจาก Solver ต้องแปลงเป็น ข้อเสนอในการวางแผนการผลิต ที่ผู้อ่านเข้าใจได้ ไม่ใช่เพียงภาพหน้าจอ Solver หรือการรายงานตัวเลขกำไร

ตัวอย่างบทสรุปรายงานสำหรับชุดข้อมูลเริ่มต้น

ชื่อเรื่อง: การวางแผนส่วนผสมการผลิตชิ้นส่วน CNC เพื่อเพิ่มกำไรด้วย Microsoft Excel Solver

วัตถุประสงค์: หาจำนวนผลิตสินค้า A และ B เพื่อให้กำไรสูงสุด โดยไม่ใช้เวลา CNC Lathe, CNC Milling และ Inspection เกินเวลาที่มี และไม่ผลิตเกินยอดสั่งซื้อ

วิธีการ: สร้างแบบจำลอง Linear Programming โดยใช้ตัวแปรตัดสินใจ 2 ตัว ฟังก์ชันวัตถุประสงค์ 600x+500y และข้อจำกัดด้านทรัพยากร จากนั้นแก้โจทย์ด้วย Excel Solver วิธี Simplex LP

ผลการวิเคราะห์: สำหรับชุดข้อมูลเริ่มต้น แนะนำผลิต A จำนวน 40 ชิ้น และ B จำนวน 20 ชิ้น ให้กำไรรวม 34,000 บาท โดย CNC Lathe ใช้ 100/100 ชั่วโมง CNC Milling ใช้ 80/80 ชั่วโมง และ Inspection ใช้ 60/65 ชั่วโมง เหลือ 5 ชั่วโมง

ข้อเสนอแนะ: Lathe และ Milling เป็นข้อจำกัดที่ใช้เต็มกำลัง ควรเฝ้าระวังเวลาหยุดเครื่องและตรวจความเป็นไปได้หากยอดสั่งซื้อเปลี่ยน แม้ Inspection จะมีเวลาเหลือก็ไม่ได้หมายความว่าแบบจำลองไม่เหมาะสม เพราะกำไรสูงสุดอยู่ภายใต้ข้อจำกัดร่วมทั้งหมด

ข้อจำกัดของแบบจำลองที่ควรเขียนในรายงาน

  • เป็นข้อมูลสมมุติเพื่อการเรียนรู้ ไม่ใช่ข้อมูลต้นทุนและกำลังผลิตจริงของโรงงานใด
  • กำไรต่อชิ้นและเวลาต่อชิ้นถือว่าคงที่; ไม่พิจารณาเวลา Setup, Rework, Breakdown และของเสีย
  • แบบจำลอง LP อาจได้จำนวนผลิตเป็นเศษส่วน จึงต้องใช้จำนวนเต็มเมื่อกำหนดแผนผลิตจริง
  • หากต้องการวางแผนหลายช่วงเวลา วัตถุดิบหลายชนิด หรือหลายสายการผลิต ต้องขยายแบบจำลองเพิ่มเติม
บทสรุปที่ดีต้องเปลี่ยนเมื่อข้อมูลเปลี่ยน: หากนักศึกษาใช้กรณีอื่นในบทที่ 12 ให้เขียนรายงานจากผลกรณีนั้น ไม่ยกข้อความ “A40 B20 กำไร 34,000” จากตัวอย่างฐานมาใช้โดยอัตโนมัติ

17.1 สถานการณ์

โรงงาน CNC รับจ้างผลิตสินค้า A และ B และมีเวลาทำงานเครื่องจักรจำกัด ผู้จัดการต้องการพิจารณาแพ็กเกจเพิ่มชั่วโมงทำงานของ CNC Lathe, CNC Milling และ Inspection สำหรับรอบการวางแผนเดียว หากเลือกเปิดแพ็กเกจ จะได้รับเวลาสุทธิเพิ่มตามที่กำหนด และต้องเสียค่าใช้จ่ายคงที่สำหรับแพ็กเกจทั้งชุด

17.2 สภาพปัญหา

บริษัทต้องเลือกว่าจะเปิดแพ็กเกจหรือไม่ เพราะชั่วโมงเพิ่มอาจทำให้ผลิตและขายได้มากขึ้น แต่ต้นทุนแพ็กเกจก็ลดกำไร ขณะเดียวกันจำนวนผลิตต้องเป็นจำนวนชิ้นเต็ม ไม่สามารถสั่งผลิต 0.5 ชิ้นเพื่อส่งมอบได้

17.3 เป้าหมาย

ผลิตสินค้า A และ B เป็นจำนวนเต็ม พร้อมเลือกเปิด/ไม่เปิดแพ็กเกจ เพื่อให้กำไรสุทธิสูงสุด

บทที่ 18 · ทำความเข้าใจตัวแปร

รู้จัก Integer Variables และ Binary Decision

จำนวนผลิตเป็น Integer เพราะผลิตเป็นชิ้น: x และ y ต้องเป็น 0,1,2,… ส่วน Binary z เป็นตัวแทนการเปิดแพ็กเกจ โดย z = 0 ไม่เปิด และ z = 1 เปิดแพ็กเกจ

z = 0 · ไม่เปิด

ใช้เวลาเครื่องจักรเดิม Lathe 100 / Milling 80 / Inspection 65 ชั่วโมง

ต้นทุนแพ็กเกจ = 0 บาท

z = 1 · เปิด

Lathe 120 / Milling 95 / Inspection 70 ชั่วโมง

ต้นทุนแพ็กเกจ = 2,000 บาท

ในโจทย์ระดับที่ 1 คำตอบเป็นจำนวนเต็มอยู่แล้ว การเพิ่ม Integer Constraint อย่างเดียวจึงไม่เปลี่ยนผลฐาน แต่การเพิ่มทางเลือกเปิดชั่วโมงทำงานกับค่าใช้จ่ายคงที่ จะทำให้มีการตัดสินใจใหม่ที่ต้องวิเคราะห์ความคุ้มค่า

บทที่ 19 · ฟังก์ชันกำไรและข้อจำกัด

สร้างแบบจำลอง MILP จากโจทย์ระดับที่ 2

19.1 ตัวแปรตัดสินใจ

x = ผลิตสินค้า A (จำนวนเต็มไม่ติดลบ), y = ผลิตสินค้า B (จำนวนเต็มไม่ติดลบ), z = เปิดแพ็กเกจชั่วโมงทำงาน (Binary 0 หรือ 1)

19.2 Objective Function

Maximize Z = 600x + 500y − 2,000z

600x + 500y เป็นกำไรส่วนเพิ่มก่อนหักแพ็กเกจ ส่วน 2,000z หักค่าแพ็กเกจเฉพาะกรณี z = 1 (หน่วยบาทต่อรอบ)

19.3 ข้อจำกัดของเครื่องจักร

2x + y ≤ 100 + 20z
x + 2y ≤ 80 + 15z
x + y ≤ 65 + 5z

ด้านซ้ายคือเวลาที่การผลิตต้องใช้ ด้านขวาคือเวลาที่มี ซึ่งเปลี่ยนตามค่า Binary หาก z = 0 จะกลับเป็นเวลาปกติ หาก z = 1 จะได้เวลาสูงสุดของแพ็กเกจ

19.4 ข้อจำกัดจำนวนผลิตและชนิดตัวแปร

0 ≤ x ≤ 45, 0 ≤ y ≤ 40, x,y ∈ ℤ; z ∈ {0,1}
เลือก Solving Method = Simplex LP ใน Solver Parameters แต่ต้องเพิ่มข้อจำกัด int และ bin ด้วย Excel Solver จะใช้กระบวนการค้นหาคำตอบจำนวนเต็มที่เหมาะสม ไม่ใช่ Simplex แบบตัวแปรต่อเนื่องล้วน
