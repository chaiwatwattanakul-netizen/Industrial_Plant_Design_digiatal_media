บทที่ 01 · รู้จักปัญหาจริง

รู้จัก Machine Loading Optimization

การจัดสรรภาระงานให้เครื่องจักร (Machine Loading) คือการตัดสินใจว่า งานชนิดใดควรถูกผลิตบนเครื่องจักรใดและจำนวนเท่าใด ภายใต้กำลังการผลิตจำกัด โดยมุ่งลดต้นทุนหรือเพิ่มประสิทธิภาพของเครื่องจักร

▤Production Planning

ตัดสินใจว่าจะผลิตสินค้าแต่ละชนิดรวมเท่าไร

⚙Machine Loading

ตัดสินใจว่าแต่ละเครื่องผลิตสินค้าแต่ละชนิดเท่าไร

◷Job Scheduling

ตัดสินใจลำดับ เวลาเริ่ม และเวลาสิ้นสุดของงาน

ขอบเขตของบทเรียน

ตัวเลขเวลาต่อชิ้นและต้นทุนต่อชิ้นเป็นข้อมูลของคู่ งาน–เครื่องจักร ไม่ใช่เวลาเดียวกันทุกเครื่อง ตัวอย่างนี้ยังไม่รวม Setup Time, ลำดับงาน, กะพนักงาน หรือค่าขนส่ง

บทที่ 02 · ทำความเข้าใจโรงงาน CNC

สถานการณ์โรงงาน CNC และเป้าหมาย

บทที่ 04 · คำนวณกำลังการผลิต

กำลังเครื่องจักรและ Utilization

ความสามารถเครื่องจักร (Capacity) ที่ใช้ในโจทย์เป็น เวลาสุทธิพร้อมผลิต ในช่วงวางแผนเดียวกัน ไม่ต้องหัก OEE ซ้ำ กำหนดการใช้กำลังเครื่องจักรตาม Used Time / Available Time × 100

เครื่องจักรเวลาสุทธิ (นาที)คิดเป็นชั่วโมง
CNC-M11,20020 ชม.
CNC-M21,00016 ชม. 40 นาที
CNC-M31,90031 ชม. 40 นาที
Machine Utilization (%) = (เวลาที่ใช้จริง ÷ เวลาที่มี) × 100

ตัวอย่างแผนตั้งต้น (Baseline) จะใช้เวลาบน CNC-M1 = 50×20 + 0×30 = 1,000 นาที ดังนั้น Utilization = 1,000 / 1,200 × 100 = 83.33%

Bottleneck ไม่เท่ากับต้นทุนต่ำที่สุด

เครื่องที่ถูกใช้เต็มกำลังอาจเป็นข้อจำกัดของแผน แต่การลดต้นทุนต้องพิจารณาต้นทุนรายคู่ งาน–เครื่องจักร พร้อมข้อจำกัดทั้งระบบ ไม่ดูเพียง % Utilization

Machine Loading ≠ Scheduling

ผลการแบ่งงานบอกจำนวนชิ้นที่จะผลิตบนแต่ละเครื่อง แต่ไม่ได้บอกลำดับงาน เวลา Setup, งานรอ และเวลาเริ่ม–เสร็จ

ข้อจำกัดของแบบจำลอง

แบบจำลองนี้ไม่มีพนักงาน, การหยุดเครื่อง, Setup Time, Tool Life, ความพร้อมวัตถุดิบ, ความแปรปรวนคุณภาพ, พลังงาน และการขนย้าย หากนำไปใช้จริงควรเพิ่มเติมข้อจำกัดหรือวิเคราะห์ความเสี่ยงก่อน
